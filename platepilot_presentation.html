🍛 PlatePilot

NutriNinja Cup

Budget-aware meal planning for college & hostel students

Live Demo · GitHub Repo

Problem

  • Students on ₹100–₹150/day often rely on noodles/fast food → nutritional deficiencies.
  • Most nutrition apps assume expensive groceries, exotic items, and full kitchens.
  • No easy tool to plan balanced meals using local staples within a strict daily budget.

Solution — PlatePilot

  • Generates budget-constrained, nutritionally balanced daily/weekly meal plans.
  • Knapsack-style optimization maximizes nutrition (protein focus) while staying under ₹ cap.
  • Hostel-friendly recipes with clear costs and simple cooking steps.
  • Works as a fully client-side web app (GitHub Pages) with optional Node/Express backend.

Core Features

  • Profiler: daily budget (₹), diet (Veg/Non-Veg/Vegan), goal (Loss/Gain/Maintenance/High Protein).
  • Meal Plan Generator: breakfast, lunch, snack, dinner + smart top-ups within budget.
  • Macro Visualizer: Chart.js doughnut + bars vs RDA targets.
  • Cost Breakdown: per-meal ingredient costs + recipes.
  • Grocery List: categorized weekly list, estimated spend, pantry highlights.
  • Meal Swap: one-click nutritionally similar alternatives.

Extras / Stretch

  • 🏠 Hostel Mess Alternative Mode: best picks + outside supplements.
  • 🥫 Pantry leftover prioritization.
  • 🖨 PDF export via browser print.
  • 💬 Community budget recipe board (localStorage).
  • 📜 Saved plans history (localStorage).

Tech Stack

HTML5/CSS3 Vanilla JS (ES Modules) Chart.js Node.js + Express JSON dataset (50 recipes) GitHub Pages

  • Optimization in-browser for static hosting; optional REST API for server mode.
  • Codebase: /root/platepilot with public/, client/ static build, server.js.

Demo Flow

  1. Set ₹120/day, Non-Veg, High Protein → Generate.
  2. Show plan cards, cost meter, and macro charts (doughnut + targets).
  3. Use Swap on one meal → totals update.
  4. Open Grocery list and Mess mode demo.
  5. Mention Saved Plans and Print/PDF export.

Example Output (typical)

  • ₹120/day High Protein (Non-Veg): approx ~2.2k kcal, ~90–100g protein, cost near ₹118.
  • Plates built from affordable staples (dal, eggs, soya, chana, rice/roti, curd/milk extras).
  • Optimization favors protein-per-rupee and calorie top-ups to meet targets within budget.
